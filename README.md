# Hi, I'm Raúl 👋

I started writing stories long before I wrote my first line of Kotlin.
Somewhere along the way I realised both crafts ask the same question: **how do you build a world that feels alive to the person inside it?**

By day, I answer it with code, building Android apps at **Mercadona IT** in Valencia 🇪🇸.
By night, I answer it with ink, writing epic fantasy set in my own universe, *Aezara*. ✍️

---

### 🛠️ What I work with

**Android:** Kotlin · Jetpack Compose · Coroutines & Flow · Hilt · Room · Navigation
**Multiplatform:** Kotlin Multiplatform (KMP)
**Backend & data:** Supabase · REST APIs · Firebase
**Craft:** Clean Architecture · MVI/MVVM · modular apps · testing

~5 years building Android apps, from first sketch to production.

---

### 🧪 What I'm building

Lately I'm all in on **Kotlin Multiplatform**: one codebase, several screens, and an architecture that has to hold up in all of them.

I'm building KMP apps for **readers, online communities and local businesses**, mostly in private repos for now. One piece is coming out in the open:

> 🧱 **KMP architecture sample** *(coming soon)*: the modular, Clean-Architecture setup I use in my own apps, stripped down into a public template you can clone, study or argue with.
